# Mis Tareas

Aplicación web para administrar tareas personales,
desarrollada como prueba técnica junior.

## Tecnologías
- PHP y Laravel
- Vue 3
- MySQL (cambio respecto al enunciado original por confirmar)
- Git y GitHub

## Funcionalidades previstas
- Crear tareas.
- Listar tareas.
- Marcar y desmarcar tareas completadas.
- Eliminar tareas con confirmación.
- Validar títulos vacíos.
- Conservar las tareas después de recargar.

## Requisitos
- PHP y Composer
- Node.js y npm
- MySQL configurado
